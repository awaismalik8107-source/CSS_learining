# Learning Log

## Purpose
This file documents lessons extracted from feedback cycles, preserving insights that refine future performance and prevent repeated discrepancies.

## Format
Each entry captures:
- **Date**: When the lesson was recorded
- **Context**: What was being attempted
- **Discrepancy**: What didn't match user expectations
- **Core Lesson**: The fundamental principle extracted
- **Applied Resolution**: How the issue was resolved
