## Project Initialization Protocol

### Phase 1: Scope Definition
- Determine total number of pages
- Document page list and intended purpose

### Phase 2: Page-by-Page Iteration
For each page, gather:
- **Content**: Text, images, multimedia elements
- **Layout**: Visual structure, component placement, responsive breakpoints
- **Functionality**: Interactive behaviors, user interactions, state management
- **Navigation**: How the page connects to other pages and the broader site

### Phase 3: Development Execution
- Follow iterative development with confirmation after each update
- Align modifications with user feedback after every edit

### Phase 4: Review and Refinement
- Confirm satisfaction after each change
- Analyze discrepancies when feedback indicates dissatisfaction
- Extract core lessons and document in learning.md

## Workflow Standards

### After Each Edit
1. Present changes to user
2. Ask: "Are you satisfied with these changes?"
3. If YES → proceed to next task
4. If NO → analyze discrepancy, extract lesson, document in learning.md, then revise

### Feedback Analysis Protocol
When user is unsatisfied:
- Identify the specific discrepancy
- Extract the core lesson/reason for the mismatch
- Document in learning.md immediately
- Revise implementation to align with user expectations
