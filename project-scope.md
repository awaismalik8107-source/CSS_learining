# Peak & Pulse Travel Agency - Project Scope

**Brand:** Peak & Pulse
**Tagline:** "Adventure, Refined."
**Target Audience:** Executive Adventurer (Ages 30-55, high disposable income)

## Color Palette
- Deep Forest Green: #1B3022
- Slate Grey: #707070
- Burnt Orange (CTA): #CC5500
- Off-White/Cream: #F5F5F0

## Site Architecture (6 Pages)

### 1. Homepage
**Content:**
- Hero: Video background (Andes sunrise)
- Headline: "Adventure, Refined."
- Featured 2026 Trips section
- "Why Choose Us" icons/features
- Live Instagram feed
- Navigation to all pages

**Layout:**
- Full-width hero with video
- Grid for featured trips (3 cards)
- 4-column icon grid for features
- Footer with newsletter

**Functionality:**
- Video autoplay (muted)
- Smooth scroll navigation
- Trip cards hover effects

### 2. Destinations
**Content:**
- Interactive world map
- Categories: Patagonia, Swiss Alps, Kyoto Hinterlands, Northern Iceland

**Layout:**
- Map visualization area
- Destination cards below

**Functionality:**
- Map hover interactions
- Filter by region

### 3. Packages/Tours
**Content:**
- Detailed itineraries
- Example: "7-Day Fjords Kayak Expedition"
- Gear lists, difficulty ratings, daily breakdown

**Layout:**
- Package cards with imagery
- Scrollable vertical timeline

**Functionality:**
- Interactive itinerary timeline
- Difficulty rating visual
- Gear checklist toggle

### 4. About Us
**Content:**
- Founders: Elias and Sarah
- Story: Former mountain guides bringing luxury to rugged terrain

**Layout:**
- Split layout (image + text)
- Team section

### 5. Contact/Booking
**Content:**
- Multi-step booking form
- Contact details

**Layout:**
- Step indicator
- Form sections with progress

**Functionality:**
- Multi-step form (Date → Group size → Dietary requirements)
- Validation

### 6. The Pulse (Blog)
**Content:**
- "How to Pack for 4 Seasons in 1 Day"
- "Top 5 Hidden Hot Springs in Iceland"

**Layout:**
- Article grid
- Featured post highlight

---

## Global Features
1. Dynamic Trip Finder (filter by Vibe: Relaxing, Heart-pumping, Cultural)
2. Social Proof Slider (testimonials with "Verified Trip" badge)
3. Gear Concierge Popup (chat with expert)
4. Responsive design (mobile-first)

## Tech Stack
- HTML5
- CSS3 (with custom properties for colors)
- JavaScript (ES6+)
- Tailwind CSS
